# 기업영업팀 매출 대시보드

- 첫 화면: `index.html` → **애터미** (`atomy/`) · **B2B 채널** (`b2b/`)
- 자료: ERP 일일판매실적조회 엑셀 (기업영업팀)

## 매일 갱신하는 법
1. ERP에서 날짜를 정해 일일판매실적조회 → 엑셀 저장 (하루치·이틀치 등 아무 기간이나 가능)
2. 이 저장소의 `input` 폴더 → **Add file → Upload files** → 엑셀 올리기 → Commit
3. 1~3분 뒤 자동으로 페이지가 갱신됩니다 (Actions 탭에서 진행 확인). 브라우저에서 Ctrl+F5.

## 규칙
- 같은 날짜가 여러 파일에 있으면 **나중에 올린 파일**이 이깁니다. 그 파일의 첫 날~마지막 날 구간을 통째로 바꿉니다. (수정·취소분을 다시 올리면 그대로 반영)
- 각 파일의 합계가 엑셀 TOTAL 행과 같은지 빌드 로그에서 확인합니다.
- 대표거래처 `개인소매` 제외. `애터미`·`애터미_수출` → 애터미 페이지, 나머지(애터미아자 포함) → B2B 페이지.
- 매출 = 원화판매금액(부가세 제외, 반품·차감 포함). 비교는 전년 같은 날짜.

## 처음 한 번 설정
Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `(root)` → Save
